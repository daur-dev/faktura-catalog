# Фактура — каталог отделочных материалов (демо)

Демонстрационный **сайт-витрина** каталога отделочных материалов. Это
портфолио-кейс: одностраничник, где посетитель смотрит ассортимент и оставляет
заявку менеджеру. **Это не интернет-магазин** — без корзины, оплаты и личного
кабинета.

Бренд «Фактура» и все данные вымышлены для демонстрации.

## Что внутри

- Шапка с навигацией, поиском и кнопкой «Связаться» (на мобильном — бургер-меню).
- Hero, блок преимуществ, сетка категорий.
- **Каталог** из 24 товаров в 6 категориях с фильтром по категориям и живым
  поиском по названию (карточки рендерятся из данных, не захардкожены).
- **Карточка товара** в модальном окне: фото, описание, таблица характеристик,
  цена «от», кнопка «Оставить заявку». Закрытие по крестику, `Esc` и клику вне окна.
- Блок «О компании», контакты и **демо-форма заявки** с валидацией (имя и
  телефон обязательны) и уведомлением-благодарностью.
- Адаптив (телефон / планшет / десктоп), плавный скролл по якорям, кнопка «Наверх».

## Технологии

Статический сайт **без сборки**: чистый HTML + собственный CSS + ванильный JS.
Никаких фреймворков и Node-зависимостей. Шрифты — Google Fonts (Inter / Manrope)
с системным фолбэком.

```
index.html      — разметка всех секций
styles.css      — стили и адаптив (своя палитра, не «дефолтный» вид)
products.js      — данные каталога: массивы CATEGORIES и PRODUCTS
app.js          — рендер, фильтр, поиск, модалка, форма, меню
img/            — изображения товаров, категорий, hero, og (JPG) + favicon.svg
img/_svg-backup/ — прежние SVG-заглушки (на случай отката; в сайте не используются)
img/_gen/credits.json — пофайловые атрибуции изображений (источник, автор, лицензия)
tools/          — служебные скрипты сборки (не входят в сайт): fetch_images.py
                  (подбор фото с Wikimedia), gen_images.py (старые SVG-заглушки), montage.py
```

## Как открыть

Просто **дважды кликните `index.html`** — сайт откроется в браузере и полностью
работает офлайн (из сети подгружаются только шрифты и могут не загрузиться без
интернета — тогда используется системный шрифт).

Для «чистого» локального запуска можно поднять простой сервер:

```bash
# Python 3
python -m http.server 8000
# затем открыть http://localhost:8000
```

## Источник изображений

Все изображения каталога — **реальные фотографии и текстуры с [Wikimedia Commons](https://commons.wikimedia.org/)**,
подобранные по смыслу под каждый товар/категорию (обои → обои, плитка → плитка и т.д.),
скачаны **локально в `img/`** (офлайн-надёжность, без хотлинков и битых ссылок) и
оптимизированы по весу (фото товара ≤ 200 КБ, hero ≤ 400 КБ; всего ~4 МБ).

**Лицензии** — только свободные: Creative Commons (CC0, CC BY, CC BY-SA) и Public Domain.
Пофайловая атрибуция (название файла, автор, лицензия, ссылка на источник) сохранена в
[`img/_gen/credits.json`](img/_gen/credits.json). Распределение по лицензиям:
CC0 — 10, CC BY-SA 4.0 — 8, CC BY 2.0 — 6, Public Domain — 4, CC BY-SA 3.0 — 2, CC BY 4.0 — 1.

> Это демо-витрина. **При сдаче реальному клиенту** изображения заменяются на его
> собственные фото товаров — имена файлов в `img/` уже соответствуют позициям
> (`oboi-1.jpg`, `pol-2.jpg` …), достаточно положить новые файлы под теми же именами.
>
> Воспроизвести подбор: `python tools/fetch_images.py` (Python + Pillow). Favicon
> (`img/favicon.svg`) — собственный логотип «Ф», не из стоков. Прежние абстрактные
> SVG-заглушки сохранены в `img/_svg-backup/`.

## Деплой

Сайт статический, разворачивается без настройки.

**Netlify (drag-and-drop):**
1. Зайдите на <https://app.netlify.com/drop>.
2. Перетащите всю папку проекта в окно браузера.
3. Готово — Netlify выдаст публичную ссылку.

**GitHub Pages:**
1. Создайте репозиторий и запушьте содержимое папки в ветку `main`.
2. Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/root`.
3. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

## Как добавить или изменить товар

Каталог data-driven — правится только `products.js`:

```js
{
  id: 25, catKey: "plitka", category: "Плитка и керамогранит",
  name: "Название товара",
  priceFrom: 1290, unit: "м²",
  short: "Короткая характеристика для карточки",
  description: "Подробное описание для модалки.",
  specs: { "Размер": "60×60 см", "Толщина": "9 мм" },
  image: "img/plitka-5.jpg"
}
```

`catKey` должен совпадать с `key` одной из категорий в массиве `CATEGORIES` —
тогда товар автоматически попадёт под нужный фильтр.
